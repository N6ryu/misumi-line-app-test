# 三角線リアルタイムナビ v25

## 方針
- 起動後、まず三角線13駅から「利用する駅」を選択する。
- 熊本方面／三角方面の切替を廃止し、上下線を同じ画面に一括表示する設計に変更。
- 今回JR九州から提供されたサンプルは 8031D / 527D の2件のみ。
- 画面上の現在時刻を **10:30固定** とした。
- 両サンプルの取得時刻は 10:28。
- 駅別発着時刻・時刻表は提供データに含まれないため、推測・補完して表示しない。
- 受領サンプル2件はいずれも direction=下り。上り表示は将来データを受領した際に同一画面へ追加する想定。
- 列車位置は受領した緯度経度を利用。
- 地図は外部CDN非依存の軽量SVG方式を継続。

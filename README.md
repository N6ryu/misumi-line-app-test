# 三角線リアルタイムナビ v34

## v34
### 地図
- Leaflet地図を「地図タブが表示された後」に初期化する方式へ変更。
- 非表示状態で初期化して一部タイルしか描画されない問題を回避。
- invalidateSize() を初期表示時と250ms後の2回実行。
- タイル読み込み完了時にも再描画。
- 列車GIFは緯度経度に紐付いたLeafletマーカーのため、ズーム・パンに追従。

### 時刻表
- 駅掲示時刻表を参考にレイアウトを変更。
- 左：上り（熊本方面）
- 中央：時（5〜23時）
- 右：下り（三角方面）
- 各時間帯の発車時刻は「分」だけを大きく並べる方式。
- 行は白／水色の交互背景。
- 列車種別・行先は各分表示の下に小さく表示。
